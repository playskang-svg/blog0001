# 포스팅 이미지

공개 글의 이미지는 `카테고리 slug/글 slug/파일명.webp` 구조로 저장합니다.

예시:

```text
src/assets/images/posts/airport-to-stay/matsuyama-airport-to-dogo/hero.webp
```

- 래스터 이미지는 WebP만 허용합니다.
- 실제 숙소·객실·시설은 사용권이 확인된 실사진 또는 공식 허용 이미지를 사용합니다.
- 파일명은 `hero.webp`, `route-map.webp`, `stay-area.webp`처럼 용도를 드러냅니다.
- 모든 본문 이미지에 자연스러운 한국어 대체 텍스트를 작성합니다.
